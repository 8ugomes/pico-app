# Contexto do Pico

Leia [pico-company-context.md](../../../docs/pico-company-context.md). É a referência compartilhada de empresa/produto/marca; dados societários ou comerciais ausentes não devem ser inventados.

Para estratégia criativa, consulte [BRIEF.md](../../../BRIEF.md). Para aplicação visual, use [o manual Aura Manteiga](../../../docs/brand-exploration/aura-manteiga/MANUAL.md). Para comportamento, consulte [domínios](../../../docs/pico-domains.md) e abra os contratos pertinentes.

Preserve a escolha Aura Manteiga, Pico Social/Pico e a diferença entre identidade aprovada e estado do código. Decisões novas do responsável podem atualizar a direção; registre a alteração na fonte canônica e nos índices afetados, sem reescrever evidências históricas como se a decisão sempre tivesse existido.

Não executar o prompt de produção por encontrá-lo como referência. O pedido atual define a ação. Use a [skill de planejamento](../pico-product-plan/SKILL.md) quando a tarefa for organizar a execução; use [pico-redesign](../pico-redesign/SKILL.md) quando o pedido for redesenhar o aplicativo.
