const escape = s => String(s).replaceAll('&', '&amp;').replaceAll('<', '&lt;').replaceAll('"', '&quot;');
function text(str, x, y, size = 30, color = C, weight = 400, family = 'manrope', max = 952) {
  const font = fonts[family][weight], run = font.layout(str);
  const advance = run.positions.reduce((n, p) => n + p.xAdvance, 0);
  const finalSize = Math.min(size, max * font.unitsPerEm / advance), scale = finalSize / font.unitsPerEm;
  let cursor = 0;
  const paths = run.glyphs.map((g, i) => {
    const position = run.positions[i];
    const path = `<path d="${g.path.toSVG()}" transform="translate(${cursor + position.xOffset} ${position.yOffset})"/>`;
    cursor += position.xAdvance;
    return path;
  }).join('');
  textAudit.push({ asset: current, text: str, x, y, size: finalSize, width: advance * scale });
  return `<g aria-label="${escape(str)}" fill="${color}" transform="translate(${x} ${y}) scale(${scale} ${-scale})">${paths}</g>`;
}

async function background(variant = 0, height = 1350, dark = false) {
  const key = `${variant}-${height}-${dark}`;
  if (!backgrounds[key]) {
    const buffer = await sharp(Buffer.from(fieldSvg(variant, 1080, height, dark))).composite([{ input: grainTile, tile: true, blend: 'soft-light' }]).jpeg({ quality: 96 }).toBuffer();
    backgrounds[key] = `data:image/jpeg;base64,${buffer.toString('base64')}`;
    await writeFile(join(out, `assets/campo-${key}.jpg`), buffer);
  }
  return bitmap(backgrounds[key], 0, 0, 1080, height);
}
