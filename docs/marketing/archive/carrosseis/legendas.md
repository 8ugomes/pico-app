## Ordem de publicação

Começar pelo carrossel 1 para apresentar o produto, depois 2 para mostrar as relações e 3 para explicar o diário privado. Dentro de cada pasta, postar `01.png` a `05.png` nessa ordem. `visao-geral.png` serve para revisão e não entra no carrossel.

Revisar a prévia no compositor do Instagram antes de postar e preservar o formato vertical 4:5. Os textos alternativos de cada imagem estão em `textos-alternativos.md`.
